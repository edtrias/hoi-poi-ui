# Spacer

The Spacer component provides a flexible way to add consistent whitespace between elements. It helps maintain proper spacing in layouts without relying on margin or padding properties directly on content elements.

## Features

-   Independent horizontal (x) and vertical (y) spacing
-   Uses design system spacing units (4px increments)
-   Simple API for consistent spacing throughout the application
-   Clean solution for spacing that doesn't affect component styling

## Usage

Horizontal

```jsx
<Spacer x={1} />
```

Vertical

```jsx
<Spacer y={1} />
```
