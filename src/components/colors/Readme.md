# Colors

The Colors component displays a comprehensive visualization of the theme's color palette. It provides a visual reference for all available colors in the design system, organized by semantic categories.

## Features

-   Displays all colors from the current theme
-   Organizes colors by categories (primary, accessible, semantic, etc.)
-   Shows color name and hex/RGB value
-   Automatically determines text contrast color for readability
-   Responsive layout for different screen sizes

## Usage

```jsx
import Colors from './index.jsx';

<Colors />;
```
