# Divider

The Divider component is a simple horizontal rule that creates a visual separation between sections of content. It helps organize content and improve readability by providing clear visual breaks.

## Features

-   Simple horizontal line for visual separation
-   Consistent styling with the design system
-   Minimal and unobtrusive appearance
-   Full-width by default
-   Lightweight with no dependencies

## Usage

Default:

```jsx
import { Divider } from 'hoi-poi-ui';

<div>
    <Divider />
</div>;
```
